# UI Style Guide

## Direction

The UI is the portable board of the Knowing One: layered route cards, circle
agreements, field notes, repair patches and clear tactical counters assembled
from printed cardboard and paper. It records living names rather than operating
a secret institution.

## Layout Rules

- Gameplay readability overrides archival decoration.
- Tower cards resemble compact craft agreements: name, circle, role, cost,
  condition and reconstruction level.
- Wave preview resembles a road-tide forecast assembled from route cards.
- Controls use large clear hit targets.
- Handwriting is reserved for corrections, discoveries and character notes.

## Materials

- deep indigo and cold stone-card for persistent HUD areas;
- warm paper and birch bark for lore and agreements;
- copper and amber for active circle links;
- burgundy folded tabs for warnings;
- exposed paperboard edges on every physical UI layer.

## Symbols

Use only original sparse accents permitted by
`../02_creative/visual-cultural-source-map-v4.md`. Do not use random runes,
copied sacred signs, current political marks or Soviet state emblems as generic
buttons.

## Typography

- compact technical sans-serif for numbers and controls;
- readable serif or humanist face for reports;
- restrained monospaced text only for technical measurements;
- no pseudo-Old-Slavic display font for normal gameplay information.

## Localization

Russian is the primary naming language. Controls and numbers must remain legible
after later English localization.
