Date: 2026-07-22

## Why v2 was rejected

The previous production branch over-generalized the first upgrade family. It treated Watchtower, Ranger and Tracker primarily as one circular platform with replaceable crossbows. That preserved technical layering but discarded the object identities stated in `asset-prompt-bible.md`.

Structural reuse is now allowed only after the complete object silhouette and gameplay description remain recognizable. Similar stats or upgrade lineage do not authorize identical bodies.

## Reuse rule

Reuse may cover material swatches, bolts, generic dust/sparks, or genuinely identical hardware. The visible base/body silhouette is object-owned unless the original description explicitly says it is the same physical structure. Upgrade lineage is represented through small motifs and compatible attachment conventions, not by copying the entire platform.

## Watchtower restart contract

Watchtower remains crossbow-based because the original description explicitly names a separate rotatable crossbow. This does not establish crossbows as the default for later tower families.

First lock one assembled projection master with:

- compact circular stone Warden's Post footprint;
- central wood/metal rotating socket;
- one lightweight simple crossbow;
- one dedicated flag station with red cloth;
- one top-view lantern station;
- readable exposed tan cardboard edges;
- exact true top-down `90°` orthographic projection.

After the master passes visual approval, generate each component separately from that master: base/body, socket, crossbow, pole/mount, cloth frames, lantern body/flame frames, bolt, muzzle FX, unique debris and shared material-appropriate destruction FX.

No Ranger, Tracker, Assassin, ballista, cannon or magic-tower assumption may influence this Watchtower master.
