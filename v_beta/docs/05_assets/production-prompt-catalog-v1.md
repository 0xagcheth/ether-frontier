## Usage

This catalog closes the per-family prompt gaps left by
`asset-prompt-bible-v6.md`. Every prompt below inherits, without shortening:

1. the universal ImageGen 2 master prefix;
2. the universal negative prompt;
3. exact true top-down orthographic 90°;
4. one coherent object or source unit per call;
5. generous safe margin on a uniform removable chroma-key background;
6. no labels, grids, pivot marks or review layout in the source image.

These are text specifications only. They are not authorization to generate.
Before production, each family receives an ordered source-call plan derived from
its approved projection master and layer contract.

## 1. Standard enemies

### `fast` — Бегун Глубин

Prompt core: small fast Lower-Serpent runner built from warm clay-print
punchboard; elongated separate legs dominate the silhouette, compact torso and
one practical obligation plate remain secondary. Separate head, torso, four
limb groups, scale flaps, dust tabs, run-cycle extremes, hit flash and clay
debris. No reptilian racial caricature, no goblin, no Grey overlays.

### `warrior` — Ратник Чешуи

plate. Separate body, head, arms, legs, weapon, shield or tool, plate, attack
arc, hit state and scale debris. No generic orc, no copied historical armour.

### `brute` — Глиняный тяжеловес

Prompt core: broad high-HP carrier assembled from heavy clay masses and

### `raider` — Крюк Имён

production work.

## 6. Character direction and animation sources

For Borislav, Ayana and Amba, create separate coherent directional masters for
N, NE, E, SE, S, SW, W and NW only after one approved neutral master.

Each family requires:

- idle directional body;
- walk contact/pass extremes;
- acquire/turn;
- attack anticipation, strike/release and recovery;
- hit;
- active ability;
- return-to-Knot;
- defeat/unbinding;
- equipment, projectile and effect children separate from the body.

Never create a single sprite sheet containing several unlabeled, geometrically
incompatible characters. Each state is generated as one controlled source unit
and later packed deterministically.

## 7. Coverage statement

This catalog plus `asset-prompt-bible-v6.md` textually covers:

- fifteen tower/building families and branches;
- three heroes;
- nineteen implemented standard enemies;
- one planned enemy;
- six bosses;
- eleven planned support/base/spawn structures;
- two trees and three stone families;
- owner-bound projectiles, impacts, debris and VFX;
- directional hero animation source requirements.

Pixel geometry, pivots and atlas rects are intentionally absent until a
projection master is generated and approved. Inventing them in advance would
make the document less production-safe, not more complete.
