## Ownership

- `00_project/`: vision, authority, and documentation governance.
- `01_design/`: gameplay and level rules.
- `02_creative/`: world, factions, tone, and lore.
- `03_art/`: visual language for sprites, animation, environment, UI, and VFX.
- `04_audio/`: music, ambience, SFX, and mix direction.
- `05_assets/`: prompts, inventory, technical contracts, and Canon Assets.
- `06_engine/`: runtime architecture and performance budgets.
- `07_pipeline/`: review flow, checklists, and approval gates.

Do not create alternate bibles, copied prompts, dated drafts, or archive folders inside `docs/`. Use version control for history.
