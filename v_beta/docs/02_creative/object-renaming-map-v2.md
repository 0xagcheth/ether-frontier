## Naming rules

- Runtime IDs do not change during the lore migration.
- Russian is the primary canon naming language.
- English localization is authored after Russian names stabilize; it must convey
  function rather than transliterate every word.
- Names must remain short enough for tower cards and wave previews.
- Mythological names are used only where the object's role supports them.
