# Ether Frontier — Campaign v5

Status: **canonical narrative mapping for the current single-board runtime**  
Updated: 2026-07-24

The current game implements one Last-Knot board rather than fifteen separate
maps. Campaign v5 therefore maps story beats to real wave milestones.

## Prologue — Pulse 1

The runtime tutorial wave now uses only Depth Runners and Scale Retainers.

Teach:

- one Road;
- Wind Watch;
- Zlato;
- simple Depth Runners;
- first doubtful Veles Fragment.

## Chapter I — Pulses 2–5: The comforting text

- Wave 2: first heavy ground body.
- Wave 3: Name Hooks begin raiding roadside structures.
- Wave 4: player must build economy rather than only weapons.
- Wave 5: Red-Scale Voivode arrives.

Reveal: two versions of the same depth treaty contradict Rada's master text.

## Chapter II — Pulses 6–10: The corrected enemy

- Wave 6: first air pressure.
- Wave 7: mixed ground/air answer.
- Wave 8: Nav witnesses appear.
- Wave 9: preparation for split threat.
- Wave 10: Prince of the Depths; second Road opens.

Reveal: serpent communities are politically divided, not one enemy species.

## Chapter III — Pulses 11–15: The useful total explanation

- Waves 11–12: captured machines force artillery/Name Stone investment.
- Waves 13–14: mixed formations and roadside raids.
- Wave 15: Three-Headed Sky Keeper.

Reveal: the Grey Editor predicts waves by turning every contradictory witness
into one origin theory.

## Chapter IV — Pulses 16–20: Purity

- Waves 16–17: elite raids test economy protection.
- Wave 18: simultaneous dual-road pressure begins.
- Wave 19: Last Knot begins losing unique owner layers.
- Wave 20: Empty-Name Engine.

Reveal: the Editor offers peace through total standardisation.

## Survival chapters

- Every 5th wave: major ground alignment.
- Every 8th: sky alignment.
- Every 12th: machine alignment.
- Wave 50: Grey Conductor, Sky Keeper, World Serpent and Empty-Name Engine
  converge.

The current endless mode is framed as the unresolved final alignment. A later
implemented campaign ending should trigger one of:

1. restored single order;
2. distributed many-road covenant;
3. Mara's closure.

## Future multi-map expansion

Separate Road maps remain a planned expansion. They may be implemented only
with actual map data, wave plans and mechanics. Documentation must not claim
they are playable today.
