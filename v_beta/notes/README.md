# Working Notes

`notes/` is for concise operational memory, not canon.

- `decisions/` — pending decisions or records that still need promotion into the
  owning canonical document.
- `handoffs/` — temporary continuation notes for unfinished work.

If a note changes game rules, art direction, asset contracts, or approval state,
move the decision into the appropriate file under `docs/` and remove the duplicate
from the note.
