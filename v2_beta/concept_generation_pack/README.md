# Ether Frontier — пакет генерации 25 концептов

Этот каталог изолирует подготовку генераций от канона, игрового кода и CLI/API.

## Состав

- `STYLE_BLOCK.md` — неизменяемый общий стилевой блок.
- `MANIFEST.md` — порядок, референсы, формат и будущие имена результатов.
- `prompts/` — пять независимых семейств по пять концептов.
- `QA.md` — проверка результата до переноса в `output/selected/`.
- `output/rejected/` — неудачные, но сохранённые варианты.
- `output/selected/` — визуально проверенные варианты.

## Правило запуска

Каждый концепт запускается отдельным запросом: `STYLE_BLOCK.md` без изменений + один нумерованный prompt core. Референсы используются только для настроения, плотности орнамента, северной монументальности и масштаба. Результаты разных номеров не объединяются в одном изображении.

Статус: пакет подготовлен; генерации отсутствуют.
