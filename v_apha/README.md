# Ether Frontier

Pre-production workspace for the Ether Frontier browser prototype and its visual asset pipeline.

## Start Here

1. Read `docs/00_project/project-vision.md` and `docs/00_project/source-of-truth.md`.
2. Read `docs/03_art/master-visual-style.md` and `docs/03_art/art-bible.md` before visual work.
3. Read `assets/README.md` before adding a file.
4. Use `docs/07_pipeline/review-pipeline.md` to move a candidate into the game.

## Project Layout

```text
game/       browser prototype and gameplay implementation
assets/     visual/audio files organized by production stage
docs/       canonical design, art, technical, and pipeline rules
scripts/    generation, cleanup, validation, atlas, and review utilities
```

The project currently contains no production visual assets. The game code is preserved as an integration target and will show missing visuals until approved runtime files are added.
