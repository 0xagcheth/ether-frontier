# Game Prototype

This folder contains the preserved browser implementation of the gameplay mechanics.

- `index.html`: prototype shell and map markup.
- `styles.css`: prototype layout and sprite bindings.
- `game.js`: state, simulation, waves, towers, enemies, and interactions.

The prototype loads engine-ready content from `../assets/runtime/`. Missing images are expected until the first approved visual batch is exported. Do not place temporary candidates in runtime paths just to make the prototype look complete.
