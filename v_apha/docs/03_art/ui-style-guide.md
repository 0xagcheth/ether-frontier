# UI Style Guide

## Direction

The UI should feel like a functional battlefield command layer made from stone, parchment, iron, wax, gold seal-light, and practical tower diagrams.

## Layout Rules

- Prioritize gameplay readability over decorative framing.
- Tower cards must be scannable and compact.
- Controls need large, clear hit targets for mobile.
- Avoid marketing-style hero sections inside the game UI.

## Materials

- Stone panels for durable HUD areas.
- Parchment for briefings and lore.
- Gold or warm white text on dark stone.
- Runic borders only as restrained accents.

## Icon Rules

Use icons for commands when the meaning is familiar. Use text labels when the action is domain-specific or ambiguous.

Tower icons should show role and faction material, not abstract app symbols.

## Typography

Text must remain readable at small sizes. Avoid ornate fonts for numeric gameplay information.
