# Project Vision

## Identity

Ether Frontier / Grimhold is a 2D near top-down with slight tilt medieval fantasy tower defense game about defending the last fortress seal against an invading Goblin Horde.

The game does not imitate any existing title. It uses its own illustrated near top-down with slight tilt fantasy language: iconic shapes, emotional color, strong material readability, and gameplay-first silhouettes.

## Non-Negotiables

- 2D assets only. No 3D renders, faux-3D models, vector art, AI gloss, or concept-art rendering.
- Fixed near top-down with slight tilt camera. Not 3/4 view, not side-view, not perspective.
- Volume comes from simplified forms, warm/cool color transitions, soft illustrated lighting, material design, and near top-down silhouettes.
- Medieval fantasy first. Magic is embedded in stone, siege craft, banners, runes, metal, wood, fire, and corruption.
- Every visual object owns its own sprite atlas. No atlas may contain unrelated objects.
- Sprite atlases are PNG plus JSON and must stay under 5 MB each.
- The enemy identity is the Goblin Horde, not generic undead, abstract void monsters, or unrelated fantasy factions.

## Product Pillars

### Last Fortress

The player is defending the final stronghold. Environments, UI, audio, and narrative should communicate age, siege pressure, and consequence.

### Readable Strategy

Every tower, enemy, projectile, resource, and path state must be legible at gameplay scale before it is beautiful at full size.

### Hand-Crafted Dark Fantasy

The game can use AI-assisted production, but the final look must read as intentional hand-crafted illustrated near top-down with slight tilt game art.

### Controlled Spectacle

Boss waves, tower impacts, and magical effects should feel powerful without drowning the tactical information.

## Anti-Goals

- No generic mobile TD brightness.
- No 3D miniature renders.
- No pixel-art requirement. The active style is clean illustrated near top-down with slight tilt game art.
- No direct imitation of any studio, franchise, game, or artist.
- No anime proportions unless explicitly approved for a specific hero skin.
- No unrelated faction experiments inside production assets.
- No shared mega-atlas that mixes unrelated object families.
